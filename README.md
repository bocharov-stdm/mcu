# mcu

Учебные лабы по курсу embedded/MCU на Raspberry Pi Pico (RP2040, Pico SDK).
Идут по возрастанию сложности: от банального блинка до консоли устройства
с разбором команд по UART/USB. Архивный репозиторий — код не рефакторится
и не доводится до продакшн-состояния, тут скорее фиксация того, что было
сделано на лабах.

## Что где лежит

- **01-blink** — классический hello world для микроконтроллеров: мигаем
  светодиодом на пине 25.
- **02-printf** — знакомство со `stdio_init_all()`/`printf` через USB и
  попутно демка по памяти RP2040: адреса стека, кучи, глобальных и
  константных переменных, чтение регистра периферии и первых байт `main()`
  по адресу. Специально не освобождает выделенную память — это часть
  задания, а не забытый `free()`.
- **02-echo** — читает символ с UART/USB и печатает его код (не байт-эхо в
  чистом виде, а разбор введённого символа).
- **02-on-off** — управление светодиодом командами `e`/`d`/`v` с клавиатуры
  хоста. Внутри есть `on_off.py`/`led.py` — заготовки скрипта для другой
  стороны (хост управляет платой через serial), они не доведены до конца
  (`led.py` — пустые заглушки), оставлены как есть.
- **02-control** — самая развитая лаба: консоль устройства с табличным
  диспетчером команд (`version`, `on`/`off`/`blink`, `blink_set_period_ms`,
  `help`, `mem`/`wmem` для чтения/записи по произвольному адресу с
  проверкой выравнивания и допустимого диапазона). Логика разбита на
  задачи (`stdio-task`, `protocol-task`, `led-task`), которые крутятся в
  одном суперлупе без блокировок.

## Сборка

Нужен [Pico SDK](https://github.com/raspberrypi/pico-sdk) и
arm-none-eabi тулчейн. Переменная `PICO_SDK_PATH` должна указывать на
склонированный SDK (или лежать рядом — см. `pico_sdk_import.cmake` в
каждой папке).

Собирается каждый проект отдельно, стандартно через CMake:

```sh
cd 02-control
mkdir -p build && cd build
cmake ..
make -j4
```

На выходе в `build/` появится `.uf2` — его нужно перетащить на плату в
режиме BOOTSEL (зажать кнопку BOOTSEL при подключении по USB, появится
флешка, кидаем файл туда).

`build/` в репозиторий больше не коммитится (см. `.gitignore`) — до этого
там лежали бинарники и файлы CMake с абсолютными путями с чужой машины,
смысла их хранить в git нет.

## Подключение

У большинства лаб вывод/ввод идёт через USB CDC (`stdio_init_all()`),
подключаться можно любым serial-монитором (`screen`, `minicom`,
`picocom`) на `/dev/ttyACM0` (или соответствующий COM-порт на Windows).
